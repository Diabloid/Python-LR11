# Python-LR11: Лабораторна робота 11. Кластеризація даних засобами scikit-learn

## Опис проекту
Репозиторій містить виконання фінальної Лабораторної роботи №11 з дисципліни Python:
- Дослідження та практичне застосування методів машинного навчання без учителя (Unsupervised Learning) за допомогою бібліотеки `scikit-learn`.
- Датасет: `Wine` (Хімічний склад вин).
- Алгоритми кластеризації: `KMeans`, `AgglomerativeClustering` (ієрархічний підхід з дендрограмою), `DBSCAN` (щільнісний підхід).
- Оцінювання якості: `Silhouette Score`, `Davies-Bouldin Index`, `Calinski-Harabasz Index`.
- Виявлення аномалій: `IsolationForest`.
- Зменшення розмірності: `PCA` (метод головних компонент), порівняння якості кластеризації до та після PCA.
- Інтерактивне прогнозування кластера для нових даних користувача (`input`).
